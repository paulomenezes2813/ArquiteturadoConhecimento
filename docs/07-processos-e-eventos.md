# Processos e eventos

## Distinção
Processo define o fluxo esperado. Instância registra execução real. Cada instância referencia uma versão específica do processo.

## Modelo inicial
`processes`, `process_versions`, `activities`, `activity_transitions`, `process_instances`, `activity_executions`, `operational_events`.

## Exemplo
Atendimento de manutenção: solicitação → classificação → acionamento → diagnóstico → resolução → encerramento. Execução concreta registra atores, horários, exceções, resultados e evidências.

## Aprendizagem
Prescritivo (deveria ocorrer) ≠ descritivo (ocorreu) ≠ analítico (hipótese explicativa) ≠ melhoria (proposta). Comparar indicadores com cautela causal.
