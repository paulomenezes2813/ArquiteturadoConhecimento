# Documentação do SCCO

Leia os documentos 01 a 09 na ordem indicada no README da raiz. Eles preservam a consolidação conceitual existente.

- `../decisions/`: decisões arquiteturais (ADRs).
- `../ontology/`: formalização futura do vocabulário universal.
- `../database/`: esquema exploratório e migrações futuras.
- `inicializacao.md`: inventário e limites desta inicialização.

Mudanças de entendimento devem indicar a fonte, o motivo e os documentos afetados. A Page [Arquitetura do Conhecimento](https://chatgpt.com/space/page_6b0040f543b48191ba926a91e0f6ea13) reúne contexto conceitual; não existe sincronização automática com o repositório.
