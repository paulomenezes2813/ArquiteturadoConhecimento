# Decisões arquiteturais

- [ADR-001 — Adotar modelo híbrido](ADR-001-modelo-hibrido.md): aceita conceitualmente; preservada integralmente.

Novas decisões recebem número sequencial e registram status, contexto, decisão, consequências e alternativas. Mudanças devem referenciar a decisão anterior e preservar o histórico.
